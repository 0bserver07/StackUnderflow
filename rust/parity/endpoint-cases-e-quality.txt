# An EMPTY non-terminal path segment. starlette compiles `{session_id}` to
# `[^/]+`, which needs at least one character, so Python never routes it and
# answers `{"detail":"Not Found"}`. axum's matchit DOES match the empty segment
# and hands the handler `""`, which the f-string renders with two spaces:
#   py {"detail":"Not Found"}      rs {"detail":"Session  not found"}
# A TERMINAL param is unaffected — `/api/static-analysis/session/` and
# `/api/context-replay/` both answer 404 identically on both sides — so this
# only surfaces where a param is followed by another segment.
!QL-quality-empty-id | GET  | /api/static-analysis/session//quality | -
!QL-grade-empty-id   | POST | /api/static-analysis/session//grade   | -
#
# A percent-encoded SLASH. uvicorn unquotes the raw path into `scope["path"]`

# handler gets `a/b`. Reproduced on three already-green endpoints — see
