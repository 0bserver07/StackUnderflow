# The telephone differ's corpus — `rust/telephone-differ.sh` reads this file.
#
# Columns, `|`-separated (surrounding whitespace stripped):
#
#   id      stable; used for the diff filename. `!` prefix = KNOWN-OPEN.
#   kind    cli | hook | probe
#   seed    the `parity/build_telephone_state.py` home this case runs in
#           (`-` for probe rows, which touch no home)
#   args    shell-quoted argv; `eval set --` splits it, so quoting is real
#   stdin   hook rows only: the payload piped to `hooks run`
#
# Both implementations get their OWN copy of the seed at the SAME path, and the
# two resulting trees are diffed after the run — which is the whole proof for
# `--ack` and for the hook interject: not just that the two printed the same
# line, but that they marked the same files seen.
#
# Provenance: every row here exists because a specific line of
# `services/agent_inbox.py` or `cli.py`'s `msg` group decides something.

# ── msg inbox: the empty floor ───────────────────────────────────────────────
# The two empty lines are chosen by the FLAG, not by the count — `"  Inbox
# empty." if show_all else "  No unseen messages."` — so both spellings need a
# row on a home that has no inbox at all AND on one where everything is seen.
T-inbox-empty        | cli | empty | msg inbox
T-inbox-empty-all    | cli | empty | msg inbox --all
T-inbox-empty-json   | cli | empty | msg inbox --json
T-inbox-empty-json-a | cli | empty | msg inbox --all --json
T-inbox-empty-ack    | cli | empty | msg inbox --ack

# ── msg inbox: the ordinary case ─────────────────────────────────────────────
T-inbox-plain        | cli | plain | msg inbox
T-inbox-plain-all    | cli | plain | msg inbox --all
T-inbox-plain-json   | cli | plain | msg inbox --json
T-inbox-plain-alljs  | cli | plain | msg inbox --all --json
# `--json` explicitly does NOT mark seen; the tree diff is what proves it.
T-inbox-json-noack   | cli | plain | msg inbox --json --ack
# `--ack` is the group's only WRITER: it renames every unseen file it listed.
T-inbox-ack          | cli | plain | msg inbox --ack
T-inbox-ack-all      | cli | plain | msg inbox --all --ack

# ── msg inbox: the bytes ─────────────────────────────────────────────────────
# `--json` is `json.dumps(indent=2)`, i.e. ensure_ascii=TRUE, while the message
# files were written ensure_ascii=FALSE. So the same em-dash is one byte-shape
# on disk and another on stdout, and the text rows show the third (raw).
T-inbox-unicode      | cli | unicode | msg inbox
T-inbox-unicode-json | cli | unicode | msg inbox --json
T-inbox-unicode-ack  | cli | unicode | msg inbox --ack

# ── msg inbox: hostile files ─────────────────────────────────────────────────
# Truncated JSON, a top-level list, `{}`, non-string fields (which go through
# CPython's `str()`), an empty file, all-falsy fields (the `or` fallbacks), a
# dotfile, a hidden sender dir, and an in-flight `.part`.
T-inbox-corrupt      | cli | corrupt | msg inbox
T-inbox-corrupt-json | cli | corrupt | msg inbox --json
T-inbox-corrupt-all  | cli | corrupt | msg inbox --all
T-inbox-corrupt-ack  | cli | corrupt | msg inbox --ack

# ── msg inbox: ordering ──────────────────────────────────────────────────────
# `sorted(base.glob("*/*.json"))` compares whole path STRINGS, and `-` (0x2d)
# sorts before `/` (0x2f) — so `mac-pro/aaa` precedes `mac/zzz`. A port that
# sorted by (parent, name) would put them the other way round.
T-inbox-sortorder    | cli | sortorder | msg inbox
T-inbox-sortorder-js | cli | sortorder | msg inbox --json

# ── msg inbox: the excerpt edge is NOT in inbox output ───────────────────────
# `msg inbox` prints `m.text` whole; only the hook path excerpts. Rowed so the
# two are proven different rather than assumed different.
T-inbox-long         | cli | long | msg inbox
T-inbox-long-json    | cli | long | msg inbox --json

# ── msg send: the legs that never open a socket ──────────────────────────────
# `parse_ssh_url` runs FIRST, for its side effect, before the payload is built —
# so a typo costs nothing and every row below returns before `ssh` exists.
#
# THE RULE FOR THIS BLOCK: a row may only name a `--to` that `parse_ssh_url`
# REJECTS. An accepted destination reaches `subprocess.run(["ssh", ...])`, which
# is a live network call and is forbidden. Two rows were written here that did
# reach it (`ssh://host/rel/path`, whose path urlparse reads as absolute, and a
# bad port the port used to swallow); both are gone, and what they were probing
# is covered by `T-argv-*` instead, where the argv is a value.
T-send-notaurl       | cli | empty | msg send --to notaurl hello
T-send-http          | cli | empty | msg send --to 'http://host/srv' hello
T-send-nopath        | cli | empty | msg send --to 'ssh://host' hello
T-send-rootpath      | cli | empty | msg send --to 'ssh://host/' hello
T-send-nohost        | cli | empty | msg send --to 'ssh:///srv/su' hello
T-send-empty-url     | cli | empty | msg send --to '' hello
T-send-noscheme      | cli | empty | msg send --to '//host/srv/su' hello
# `SSH://host/srv/su` is NOT here: `urlparse` lowercases the scheme, so the URL
# is ACCEPTED and the row spawned ssh — the exact rule this block states, broken
# by the row written to test it. The lowercasing is proven at `T-argv-upper`,
# where the argv is a value and nothing is executed.
# DIV-440 — the port used to silently DROP an unparseable port and go on to
# spawn ssh; the reference raises `ValueError` from `urlparse().port` and never
# gets there. Fixed in `stax-sync::ssh_store`; these rows are what crosses it.
T-send-badport       | cli | empty | msg send --to 'ssh://host:notaport/srv' hello
T-send-port-range    | cli | empty | msg send --to 'ssh://host:99999/srv' hello
T-send-port-neg      | cli | empty | msg send --to 'ssh://host:-1/srv' hello
T-send-port-double   | cli | empty | msg send --to 'ssh://host:1:2/srv' hello
# KNOWN-OPEN: clap owns the PARSER's errors and Click owns its own. Recorded as
# a class in `PARITY-wave1-resume.md` D-2 / DIV-240 and shared by every ported
# node; these two rows carry the measured bytes for THIS node rather than
# leaving the class untested here.
!T-send-missing-text | cli | empty | msg send --to 'ssh://h/srv'
!T-send-missing-to   | cli | empty | msg send hello
