# The wave-6 sync differ corpus.
#
# TAB-separated: <id> <op> <arg>… — one process per implementation per row,
# stdout compared byte for byte. `rust/sync-parity.sh` runs it; the two halves
# are `rust/parity/sync_parity.py` and `stax-sync-parity`.
#
# Tokens the harness expands to a PRIVATE, per-case, per-implementation path:
#   @A @B @EMPTY @MERGED   a copy of the matching fixture store
#   @BUCKET                an empty directory (the object store)
#   @STATE                 an empty directory (the sync state dir)
# Nothing here touches the maintainer's store, and no case reaches a network.
#
# Binary/whitespace arguments are base64. A `-` means "absent" (argv cannot
# carry None). Rows are grouped by the reference file they exercise.
