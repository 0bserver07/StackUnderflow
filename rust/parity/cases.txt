# WAVE 8 — tranche 1: the read-only and config verbs.
#
# `C-*` ids. Most of these carry a `@home[:SEED]` cwd token: the verb WRITES
# (or, for `clear-cache`, prints a different number of lines depending on what
# it found), so it cannot run against the shared state — the Python run goes
# first and would leave the store the Rust run then reads. The harness gives
# each implementation its own fresh copy of `rust/parity/homes/SEED`, at the
# SAME path, and diffs the two resulting trees as part of the case. So each row
# below proves three things: the stdout bytes, the exit code, and the bytes left
# on disk.
#
# `status` is the exception: it is read-only on the `--no-auto-ingest` branch
# and needs a real store, so it runs on the shared states like every other read
# verb. The DEFAULT branch (auto-ingest on) is deliberately unrowed — it would
# run a real ingest+backfill pass against the shared state. See DIV-238.
# ═════════════════════════════════════════════════════════════════════════════
