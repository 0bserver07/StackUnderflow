#
# T-*  rows. Three mechanisms are in play and each is named where it is used:
#   · `@home[:SEED]` — a case-local home, diffed recursively after the run.
#   · cwd token `home` — run INSIDE that home, with `$HOME` pointed at it, so a
#     `--scope project` installer writes into the diffed tree and never into this
#     worktree, and `--scope user` never into the maintainer's real ~/.claude.
#   · stdin is /dev/null for every row, which is what makes `backup restore`'s
#     `click.confirm` abort deterministically instead of reading a terminal.
#
# `backup create` is NOT here: its directory name is `datetime.now()` to the
# second, so two runs never agree. It is proven by `rust/backup-differ.sh`
# (argv interception + a real run on scratch trees). Same reason wave 5 proved
# its six wall-clock rows off-matrix.
