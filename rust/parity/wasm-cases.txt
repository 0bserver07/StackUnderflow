# wave-9 CLI-vs-wasm cases — three TAB-separated fields:
#
#   id <TAB> the native `stax` argv <TAB> the wasm request JSON
#
# Both sides are written out in full, on purpose. A case file that described
# the query once and had the harness *translate* it into two invocations would
# be a third implementation sitting between the two under test, and the wave-8
# lesson ("a differ that under-reads agrees by accident") applies twice as hard
# when one side is a JSON API and the other is argv.
#
# Placeholders the harness substitutes (and nothing else):
#   @NOW@        epoch seconds, one value for the whole run
#   @CWD@        the directory the native CLI is run from
#   @STOREPATH@  the store the native CLI opens, for the `store` verb's header
#
# The wasm side always passes `now_epoch` and `cwd` explicitly because a browser
# has neither. Every options block that omits `weights`/`budget_default` is
# taking this crate's defaults, which are the reference's defaults
# (0.5,0.2,0.3 and 2000) — a case that set them would be testing the harness.
